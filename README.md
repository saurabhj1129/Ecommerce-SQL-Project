# 🛒 E-Commerce SQL Project

This project is a complete **E-Commerce Database Management System** built using **MySQL**.
It demonstrates how an online shopping platform manages users, products, orders, payments,
and inventory using SQL.

---

## 📌 Project Features
- User Management
- Product & Category Management
- Order Processing
- Payment Tracking
- Inventory Management
- Advanced SQL Queries
